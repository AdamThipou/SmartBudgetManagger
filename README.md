SmartBudget Manager
Overview
SmartBudget Manager is a user-friendly Excel workbook designed to simplify personal financial tracking. It allows users to record daily income and expenses, automatically calculate monthly balances, categorize spending, and visualize financial health through an interactive dashboard.
Prerequisites / System Requirements
To use SmartBudget Manager, you need one of the following compatible spreadsheet applications:
* Microsoft Excel 2016, 2019, or 2021
* Microsoft 365
* An equivalent spreadsheet software capable of handling `.xlsx` files, formulas (`SUMIFS`), and conditional formatting.
Workbook Structure
The workbook consists of three primary worksheets:
1. Dashboard: Your central hub for viewing monthly balance, totals, and expense distribution charts.
2. Transactions: The ledger where you input all incoming and outgoing financial transactions.
3. Categories: The reference sheet listing standard expense categories (Food, Transport, Rent, Health, Education, etc.).
Getting Started
1. Open the file `SmartBudget_Manager.xlsx` in Microsoft Excel.
2. Navigate to the Transactions worksheet to begin logging your income and expenses.
3. Switch over to the Dashboard sheet to monitor your automated balance updates and expense charts in real time.
